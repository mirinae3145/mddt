# Special cases

This document lists the rules figure-check applies to gel and blot images, to figures reused from earlier publications, and to supplementary figures.
They apply in addition to the rules for the figure's type.

## Rules

The special cases are:

- **Gel and blot images**: Splicing lanes without marking the splice is a must-fix integrity issue.
- **Reused figures**: A figure reused from an earlier publication needs a permission note in the caption.
  - A missing note is a should-fix issue.
- **Supplementary figures**: Supplementary figures are checked with the same rules as the main figures.
  - They are reported in a separate section, as [report](../report.md) describes.
